# NN Switch v.1.0

First stable Windows release.

## Highlights

- Portable single-file EXE: no installation and no separate .NET runtime.
- Tray-only interface with the new NN icon.
- Autoswitch for conservatively detected Russian and English words.
- Selected text, last word, and active text field switching.
- Dynamic direct-to-language hotkeys for every installed Windows layout.
- Any single key or key combination can be assigned.
- Per-layout switch targets.
- Clipboard contents are restored after text replacement.
- Compact dark interface.

## Requirements

- Windows 10 or newer
- x64 processor

The executable is currently unsigned, so Windows SmartScreen may display a warning
on first launch.
